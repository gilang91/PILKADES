# Rekap Saksi Pilkades Desa Nyalindung

Proyek Android WebView dengan prototipe HTML offline.

## Fitur yang tersedia pada versi ini
- Input dan rekap hasil TPS secara lokal
- Akun saksi dapat dibuat dari Pengaturan oleh admin
- Akun saksi tidak dapat membuka Pengaturan / manajemen akun
- Menu Obrolan lokal, tersimpan di perangkat
- Ekspor/impor cadangan data

## Batasan penting
Akun, rekap, dan obrolan saat ini tersimpan lokal pada satu perangkat. Akun saksi yang dibuat di satu HP tidak otomatis tersedia di HP lain. Sinkronisasi real-time lintas perangkat dan chat online memerlukan backend/server dan koneksi internet; fitur itu belum diaktifkan dalam proyek ini. Jangan gunakan sebagai satu-satunya salinan data pemilihan.

Untuk membangun APK, buka proyek di Android Studio dan jalankan Build > Build APK(s). Android SDK dan Gradle diperlukan.
